EXPERIMENT 07
Title: String Operations in Bash and C

AIM
Extract a substring, find string length, and compare execution time for equivalent Bash and C programs.

SETUP
Ubuntu with Bash and GCC. Use ASCII text when comparing results: Bash can count characters according to the locale, while this C example counts bytes.

PRACTICAL TASKS
1. Run both versions with the string Operating Systems, start 1, length 9.
2. Confirm that the substring is Operating and the full string length is 17.
3. Try a string containing spaces, zero length, a range past the end, and an invalid starting position.
4. Compare execution times using identical redirected input. Repeat runs and record variability; do not include compilation time.

PROGRAM 1: substring.c

The runnable source is provided in substring.c.

#include <ctype.h>
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static int read_number(const char *prompt, long *value) {
    char input[64], *end;
    printf("%s", prompt);
    if (!fgets(input, sizeof input, stdin)) return 0;
    if (!strchr(input, '\n') && !feof(stdin)) return 0;
    errno = 0;
    *value = strtol(input, &end, 10);
    if (end == input || errno != 0) return 0;
    while (isspace((unsigned char)*end)) end++;
    return *end == '\0';
}

int main(void) {
    char str[1024];
    long start, len;

    printf("Enter a string: ");
    if (!fgets(str, sizeof str, stdin)) return 1;
    if (!strchr(str, '\n') && !feof(stdin)) {
        fprintf(stderr, "Error: input string is too long (maximum 1022 bytes).\n");
        return 1;
    }
    str[strcspn(str, "\n")] = '\0';
    size_t length = strlen(str);

    if (!read_number("Enter starting position (1-based): ", &start) ||
        !read_number("Enter substring length: ", &len) ||
        start < 1 || (size_t)start > length + 1 || len < 0) {
        fprintf(stderr, "Error: use a start from 1 to string length + 1 and a nonnegative length.\n");
        return 1;
    }

    size_t offset = (size_t)start - 1;
    size_t count = (size_t)len;
    if (count > length - offset) count = length - offset;
    printf("Substring: ");
    fwrite(str + offset, 1, count, stdout);
    printf("\nString length: %zu\n", length);
    return 0;
}

PROGRAM 2: substring.sh

The runnable source is provided in substring.sh.

#!/bin/bash

printf 'Enter a string: '
IFS= read -r str || exit 1
printf 'Enter starting position (1-based): '
IFS= read -r start || exit 1
printf 'Enter substring length: '
IFS= read -r len || exit 1

# Limit numeric input before using Bash integer arithmetic.
if [[ ! "$start" =~ ^[0-9]{1,9}$ || ! "$len" =~ ^[0-9]{1,9}$ ]]; then
    echo 'Error: use a positive starting position and a nonnegative length.' >&2
    exit 1
fi
start=$((10#$start))
len=$((10#$len))
if (( start < 1 || start > ${#str} + 1 )); then
    echo 'Error: starting position must be between 1 and string length + 1.' >&2
    exit 1
fi

printf 'Substring: %s\n' "${str:start-1:len}"
printf 'String length: %s\n' "${#str}"

HOW TO EXECUTE
Run these commands from this lab folder:

bash substring.sh
gcc -std=c11 -Wall -Wextra -Wpedantic substring.c -o substring
./substring

# Use identical input for timing, excluding human typing time.
printf 'Operating Systems\n1\n9\n' > /tmp/os-lab-07-input.txt
time bash substring.sh < /tmp/os-lab-07-input.txt
time ./substring < /tmp/os-lab-07-input.txt

Both programs use a 1-based starting position. A start at string length + 1 returns an empty substring; a substring extending past the end is truncated. The C input buffer supports lines up to 1022 bytes. Tiny timing results include program startup and can vary between runs.
