# Lab 04 — Processes and Terminal Editors

## Objective

Inspect processes, practise shell job control, and edit files using nano and vi/vim.

## Setup

An Ubuntu terminal with nano and vi or vim available.

## Practical work

Use `process-editor-exercises.txt` as the walkthrough. Practise job control with the sample sleep process, then create and display a file with each editor.

Check the job number or process ID before sending a signal. In vi, press Esc before entering `:wq` to save and exit.

## Observations and result

Record the commands or steps you completed, the output you observed, and any difficulties. Add your own screenshots to `screenshots/`; useful evidence includes process listings, background jobs, both editors, and saved file contents.

Complete the result after performing the practical work.
