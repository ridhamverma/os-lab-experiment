# Lab 02 — Linux Command Basics

## Objective

Practise navigation, file operations, text commands, and system information commands in the terminal.

## Setup

An Ubuntu terminal on a physical system or virtual machine.

## Practical work

Work through `command-reference.txt`, then try the practice session. Check the current directory before moving or deleting files.

## Observations and result

Record the commands or steps you completed, the output you observed, and any difficulties. Add your own screenshots to `screenshots/`; useful evidence includes navigation, file operations, text output, and system information.

Complete the result after performing the practical work.
