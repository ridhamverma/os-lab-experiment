# Lab 01 — Ubuntu in a Virtual Machine

## Objective

Set up Oracle VirtualBox, create a virtual machine, and install Ubuntu.

## Setup

VirtualBox, a compatible Ubuntu ISO, and enough host resources for the guest.

## Practical work

Follow the installation sequence in `installation-steps.txt`. Verify that Ubuntu starts and that you can sign in to the desktop.

Install using the virtual machine’s virtual disk. The worksheet contains the download links and suggested configuration.

## Observations and result

Record the commands or steps you completed, the output you observed, and any difficulties. Add your own screenshots to `screenshots/`; useful evidence includes vM configuration, installation progress, and the Ubuntu desktop.

Complete the result after performing the practical work.
