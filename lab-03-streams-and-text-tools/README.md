# Lab 03 — Streams, Pipes, and Text Tools

## Objective

Explore standard input, output, and error streams; combine commands with pipes; search and transform text.

## Setup

Ubuntu, a terminal, and a practice directory for sample files.

## Practical work

Follow `text-processing-exercises.txt` in order. Compare the output of `grep`, `sed`, and `find`, and inspect the files produced by redirection.

`>` replaces existing output files; `>>` appends. The sed examples display changes or write a separate file.

## Observations and result

Record the commands or steps you completed, the output you observed, and any difficulties. Add your own screenshots to `screenshots/`; useful evidence includes redirection, pipelines, matching lines, substitutions, and file searches.

Complete the result after performing the practical work.
